# Rules for any agent working on this repo

This is the public website for MoreHuman Ed. Treat everything here as public.

## How to work
- Pages are generated by `tools/generate-pages.py` (plain Python, no dependencies). Edit that file and run `python tools/generate-pages.py`. Do not hand-edit generated HTML. No new dependencies and no third-party scripts without approval.
- Do not change fonts, colours, the logo or `assets/tokens.css`. See DESIGN-SYSTEM.md.
- Keep `/en/` and `/es/` separate. Never mix languages on one page.
- Voice: warm, humble, curious. See PLAN.md. No em dashes, semicolons, hashtags or emojis.
- The `discovery-lab/` folder is synced automatically from another project. Do not edit it.

## Never
- Add anything that sells, offers, advertises or invites enquiries about training, workshops, consultancy or any service.
- Add booking links, contact forms, sign-ups or tracking.
- Include learner, family or colleague names or anything identifiable. Use invented examples and say so.
- Mention or imply anything from an employer, its systems, students, staff or branding.
- Claim hours saved or any outcome without a source.
- Publish testimonials.
- Change hosting, DNS or the domain.
- Store passwords or tokens in the repo.
